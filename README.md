# Frosta Tobak & Livs V10 – GitHub Pages

Ladda upp alla filer i denna mapp till roten av ditt befintliga GitHub-repository.

## Publicera
1. Öppna repositoryt på GitHub.
2. Välj Add file och sedan Upload files.
3. Dra in samtliga filer från denna mapp.
4. Välj Commit changes.
5. Kontrollera under Settings och Pages att källan är Deploy from a branch, main, /root.

Kontrollcentret kan spara utkast på enheten och publicera site-data.json via GitHub.
