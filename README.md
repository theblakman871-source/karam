# Frosta Modern V8 — Studio

Stor uppdatering från V7.

Nyheter:
- Frosta Studio V8: helt omgjord adminupplevelse med kontrollcenter, snabbåtgärder, lagerstatus, väntande media och lokala utkast.
- Varukorgen är ombyggd: plus/minus, tydlig Ta bort-knapp, töm varukorg, fortsätt handla, radtotaler, produktbilder och lagerspärr.
- Modernare mikrointeraktioner och toast-notiser.
- Alla V7-data och GitHub-inställningar är bakåtkompatibla.
- 60 MB videogräns behålls.
- Checkoutgränssnittet är förberett men riktig betalning kräver en extern godkänd betal-/åldersverifieringslösning.

Ladda upp filerna till repositoryts rot. Behåll site-data.json för befintligt innehåll.
